# Project Reef

Michael Shepherd's interactive 3D portfolio. Orbit the reef and select an animal to open its project. The Projects directory also works when WebGL is unavailable. About me includes contact links and a downloadable Resume.

The reef, animals, and shipwreck are generated in TypeScript with Three.js. Vite builds the site into `dist/`.

## Run locally

Use Node.js 20.19+ or 22.12+.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

The earlier studio portfolio is preserved in Git history and its changelog is under `docs/changelog/`.
